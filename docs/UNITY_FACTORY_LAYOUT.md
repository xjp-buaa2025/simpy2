# 工厂布局使用说明

## 日常使用

1. 启动 SimPy 服务、新版 PC 程序和新版 VR 应用，两端使用同一 SimPy 服务地址。
2. PC 点击 **显示设置 → 工厂布局 → 导出 Excel**。
3. 在“工位布局”表修改数据。保留完整 79 个编号、原表头和文件格式；从“可选模型”表选择模型。
4. 点击 **导入并预览**，选择 `.xlsx` 或 `.json`。检查通过后共享仿真暂停，候选布局仅在本机显示。
5. 检查变更列表及工厂画面。点击 **应用并同步 VR** 发布，或 **取消预览** 恢复已发布布局。
6. 保持暂停，确认面板显示 PC、VR 使用同一布局版本后，点击 **播放** 继续。

“恢复默认”和“回退上一版”也会先预览，再点击应用。每次发布都生成新版本，旧版本保留。导出的是服务端已发布布局，不包括尚未发布的预览。

## 参数

- X/Z 使用当前工厂坐标，单位米；Y 自动落地。0° 朝世界 +Z（北），正角度向右转。
- 统一缩放 1 保持该工位标准尺寸，允许 0.25～3；不允许单轴拉伸。
- 修改显示名称和区域不更改工序编号，也不会被重新排产覆盖。
- 关闭“显示设备”后保留编号、状态泛光和地面轮廓；仍保留占地、导航限制及排产事件。
- 标签高度为设备顶部以上的米数，允许 0.1～5。
- 动画开关只控制兼容动作，不改变排产和运输任务时间。
- 自动停靠优先选择能安全接入原通道的设备边缘。手动停靠偏移为工位局部坐标，随角度和缩放变化；停靠朝向为相对工位角度。
- 龙门架目前绑定 A001；可移动、旋转、缩放，不支持在其他工位复制第二套吊装动画。
- 布局启用后，“工业装饰”控制固定陈设；工位模型由布局中的模型编号和显示开关管理。

## 边界

现有 79 个工位可配置，不支持增删工序、修改物流主通道、移动厂房及烘焙陈设，也不支持在 APK 中直接导入任意 FBX。新模型需要先制作 PC/VR 对应资源并更新安装包。

布局不会修改 SimPy 工时、人员、产能、排产结果、已完工数量和共享时间。AGV 路线按新停靠点和原通道重算，保留原任务顺序及展示时间。原通道附近的已有障碍通过局部绕行处理，不创建新的物流网络。

## 诊断与恢复

- **服务未连接**：确认 SimPy 服务在运行，两端可访问同一 8000 端口；视频回传 8011 端口不负责布局。
- **404 / 没有布局入口接口**：服务端版本仍旧，重新启动更新后的 SimPy 服务。
- **排产或布局变化**：取消并重新导入预览，不直接覆盖其他 PC 的新版本。
- **没有控制权**：当前已有其他 PC 控制播放；该 PC 可以观看，不能发布布局。
- **占地/停靠错误**：面板列出工位编号、字段和原因。调整表格后再次导入。不要移除错误行凑数。
- **VR 待同步或失败**：保持暂停，检查模型目录版本、服务地址和网络。VR 保留上版，完整拿到新布局及路线后再切换。
- **离线启动**：使用该服务地址下最后成功应用的缓存；没有缓存时使用随包默认场景。

服务端依赖随 `requirements.txt` 提供，Excel 读取使用 `openpyxl>=3.1.5,<4`。在新的 Python 环境部署时先安装依赖。模板由 Artifact Tool 制作；服务导出只替换模板中的工位数据，保留格式和下拉选择。

## 版本与真机验收

PC 和 VR 必须同时更新。VR 为 `com.xjp.enginefactory.vr`，versionCode **10**，版本 **1.0.20261015.0**，保持原签名。

已在独立 HTTP 服务和 Unity 编辑器中检查默认回导、文件导入、预览取消、发布同步、版本冲突、重复切换、重新排产、三种 PC 分辨率及原 VR 导航回归。测试明细见随项目保存的验证结果。

当前没有连接 Rhino X Pro。真机仍须检查：双眼显示、左杆瞬移、右杆高度/转向、新占地阻挡和玩家安全复位、AGV 停靠、视频回传，以及连续运行 15 分钟的帧时间和内存。编辑器通过不代表真机性能通过。
