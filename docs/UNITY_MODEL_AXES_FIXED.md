# 工厂模型轴向修正 · 2026-10-09

工程：`C:/AllUnityProjects/MainProject/MainProject`，Unity 2021.3.45f2c1。记录目录：`results/unity_validation/model_axes_fixed_20261009`。

## 检查与修正

对当前10个 FBX 设备／装饰模板，以及6个已导入的 Plant Simulation 模板做隔离几何摄影。依据台面、轮子、支脚、槽口与操作面检查，不再把参数一致当成几何朝向正确。

| 模型 | 结论及处理 |
|---|---|
| 清洗机 | X 从 −90° 改为0°，轮子向下、洗篮开口向上；S002、S003 |
| 液氮柜 | X 从 −90° 改为0°，上开盖和三个槽口向上；P011 |
| 测试台 | X 从 −90° 改为0°，台腿向下、台面向上；10个气密／热试车工位 |
| 六自由度云台 | 备用模板 X 从 −90° 改为0°，上下平台水平；当前工序未启用该模板 |
| 工具工作台 | X 从0°改为180°，轮子向下；PC厂房边缘2张 |
| 待检架、储物架 | −90°正是正确的导入轴，保留 |
| 重装液压工作台 FBX | 实际为长线组合几何，当前未用于单工位；保留正确的 −90°，不强行改为0° |
| 数据分析 FBX | 当前未启用的散件展示，未找到整机落地基准；原资产保留，不据孤立散件猜测旋转 |
| 龙门吊梁 | 梁水平、链条向下，保留0° |
| Plant Simulation 6类模板 | 装配台、压机、包装台、检验台、维修台与机械臂没有发现同类轴向问题；保留 |

测试台所覆盖的工位：P013、P062、D042、G023、G052、F013、F062、A006、A007、Q001。新增柜体、屏幕、夹具和探头按实际台面高度与深度放置：柜体／夹具底部接触台面，探头底部接触夹具，设备不超出台面投影，屏幕面朝既有操作面。

共享运行时姿态配置修正 PC 与 VR；原始 FBX、Plant Simulation 网格、VR 近中远网格、材质、光照和四个场景文件均不改写。VR三级 Renderer 同属主模型，统一继承修正旋转，无需重新减面或增加网格。导航障碍仍由修正后的设备几何范围生成。
