# Unity 工人头顶进度条

更新时间：2026-10-20。工程：`C:/AllUnityProjects/MainProject/MainProject`。

PC 点击工位进入生产特写后，显示该工位每位可见工人的任务进度。返回全景、切换到工区或跟随 AGV 时隐藏；切换工位时重新选择显示人员。VR 在观察者距离工人 8 米以内时自动显示，超过 10 米后隐藏，边界之间保留之前的距离状态。镜头后、视野外以及实体碰撞遮挡时隐藏。

正常作业使用蓝条，返工使用紫条，休息显示灰色轨道和“休息”。无任务人员继续沿用原有隐藏规则。进度条只包含百分比或状态文字，不增加人员编号。

## 数据与展示

- 每位工人复用已有 `PcWorker.id / stationId / task` 绑定，按自己的任务计算进度，不读取工位汇总进度。同一任务的协作人员显示相同进度。
- 复用 `Progress(task,currentMinute)`，计划结束时间参与期末未完成任务的分母计算。暂停、拖轴、倍速及重新发布回放均跟随现有共享时钟；不修改后端接口和排产算法。
- PC 使用现有屏幕标签层，尺寸为 84×24 参考像素，按人员编号稳定排布，避让工位标签和界面面板，错位时显示细引线。
- VR 使用第 29 层的世界空间 Canvas，宽约 0.48 米，朝向观察者。头顶锚点由人物顶部换算为本地位置缓存，世界高度再加 0.15 米。
- `SimPyWorkerProgressPresenter` 在执行顺序 1100 的 `LateUpdate` 更新位置，位于 PC 镜头和执行顺序 1000 的 VR 导航之后。数值约每 0.1 秒刷新，文字仅在百分比或状态变化时改写。
- UI 与人物模型层级分开，关闭图形射线接收，不增加人物 Renderer、骨骼、动画或寻路。实心 Image 通过左侧锚定矩形宽度表示进度，避免无 sprite 时 `Image.fillAmount` 不改变画面的情况。
- 人员重新索引时先停用、销毁旧条，再创建并绑定新条；退出时统一释放。每位真实人员对应一个展示对象。

主要代码为 `Assets/Scripts/SimPyReplayWorkerProgress.cs` 和 `SimPyWorkerProgressPresenter.cs`，生命周期入口位于 `SimPyReplayPCWorkers.cs`。PC、通用 UI 和 VR 验收探针均增加 `worker_progress` 数据，包含人员、工位、事件、状态、文字、逻辑进度、实际填充比例、Canvas 类型、可见性及头顶位置。
